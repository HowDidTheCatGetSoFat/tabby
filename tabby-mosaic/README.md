# Tabby Mosaic Plugin

Tile and manage Tabby's tabs and windows.

- Tile the open tabs of a window into one split as a grid, columns, rows or master-stack
- Optional auto-rearrange when tabs are opened or closed
- Open every profile in a group at once, tiled together
- Move a tab out into its own window (keeping the live local session)
- Tile or cascade all windows, across one or all monitors
- Switch between windows, close other windows, or gather every window's tabs back into one

Actions are available from the toolbar, the tab context menu, the command palette and bindable hotkeys, and can be configured from the Mosaic settings tab.
